# Лабораторная работа №1 по курсу Теория Формальных Языков (Рефал)

## Задание:

Везде в задачах подразумевается, что строка - в алфавите латинских строчных букв, переменная - в алфавите заглавных латинских, строка окружена маркерами начала `^` и конца $. В некоторых задачах также встречаются скобки - это единственный вид скобок, круглые `()`. Образцы в левых и правых частях правил даются исчерпывающе: `^P1$ = ^P2$`, где `P2` не содержит свежих переменных, не входящих в `P1`. Подразумевается, что получившиеся системы переписывания строк должны быть эквивалентны системам переписывания образцов именно по модулю слов, имеющих представление `^[a-z]*$` (или `^[a-z]|)|($`, если в условии встречаются скобки).

9. Скобки и одна переменная. Дано единственное правило переписывания образца с одной переменной, которое может содержать скобки. Сопоставление должно уважать скобочную структуру.

## Идея решения.

1. Ищем предположительный X и заключаем его в квадратные скобки.

2. Проверяем, найденный X на ПСП. Если найденный X - ПСП, то продолжаем идти по строке сравнивая последующие вхождения X с найденным.
Если же найденный X - не ПСП, то продолжаем искать другую правую границу X.

3. Если сопоставление удалось, то в конце строки начинаем создавать новую. Приписываем в конец шаблон правой части, где все X заменены на {}. Если сопоставление не удалось, то строка возвращается в исходное состояние. 

4. Последовательно переносим символы из X в квадратных скобках в фигурные скобки.

5. Удаляем изначальную строку, оставляя только полученную часть. Затем удаляем фигурные скобки.

## Обозначения

### Буквенные обознаения.

`ALPHA` - `[a-z], (, )`

`BETA` - `[a-z], (, )`

`GAMMA` - `[a-z], (, ), ], ?, {, }`

`LAMBDA` - `[a-z], (, ), ], ?, {, }`

`DELTA` - `[a-z], (, ), ], ?, {, }, +`

**Ограничения**:

`BETA` в правиле с `GAMMA` строго неравны. 

`LAMBDA` может быть равна `GAMMA`. 

### Типы кареток.

`|CLS|>|...|` - каретка для поиска окончания X. 

`<|PSP|` - каретка для начала алгоритма для проверки найденого X на ПСП.

`<|PSP_COPY|`, `|PSP_COPY|>` - каретки для поиска скобок в X

`|COPY_O|>`, `|COPY_C|>` - каретки для копирования скобок

`<|PSP?|`, `|PSP?|>` - каретка для проверки скобочной последовательности на ПСП

`|PSP+|>`, `|PSP-|>`, `<|PSP+|`, `<|PSP-|` - каретки для обозначения ПСП X (+ - ПСП, - - не ПСП)

`<|HUNTER|` - каретка для удаления знака @ в X

`<|BACK|` - каретка, сигнализирующая неправильный выбор X

`|SR|>|...|` - каретка для сравнения символов

`<|UK..|` - каретка для поиска следующего символа в X

`|SKIP!...|>|...|` - каретка для поиска метки !...!

`<|DEL|` - каретка для удаление символов после X

`|NAR|>|...|` - каретка для наращивания X в новой строке 

`<|OK|` - каретка для поиска следующей буквы X (для наращивания)

`<|ALL|`, `|ALL|>` - каретка для полного удаления начальной сроки

`|CLR|>` - каретка для удаления вспомогательных символов

`|END|<` -каретка, обозначающая неудачное сопостовление 

**Примечание:** В частном случае для некоторых кареток искомая подстрока может оказаться 
пустым словом. Для обозначения используется `|EMPTY|`. Например, `|CLS|>|EMPTY|`

### Замечание

Предполагается, что правила с конкретными подстроками имеют приоритет над правилами с буквенными обозначениями.

Например, правило `=>|aa|aa` будет иметь приоритет над `=>|aa|GAMMA` в случае строки `^=>|aa|aa$`.
